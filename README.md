🎂 Interactive Birthday Website

A personalised birthday website created as a front-end web development project.

🌸 Overview

This project is a personalised interactive birthday website designed to create a fun and memorable digital birthday experience.

The website combines a customised visual design with images and birthday audio to create a personalised experience for the recipient.

✨ Features

* 🎂 Personalised birthday experience
* 🖼️ Custom images and visual assets
* 🎵 Birthday audio
* 💻 Web-based interface accessible through a browser
* 📱 Designed as a personal front-end web project
